# NutriFit - Healthy Weight & BMI Companion

A responsive BMI and healthy weight range web app with dynamic age-standard adjustments, visual body composition spectrum indicators, and personalized whole-food affiliate links.

## Files
- `index.html`: Structure, forms, and modal dialogs.
- `style.css`: Glassmorphic layout, button pop styling, and BMI spectrum needle animations.
- `app.js`: Clinical calculations, unit conversions, and interactive triggers.

## Usage
1. Unzip the archive.
2. Double-click `index.html` to run in any browser, or upload the directory directly to GitHub Pages / Capacitor.
